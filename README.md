A modern, full-stack web application built using Next.js/React for the frontend and Node.js for the backend, utilizing Axios for robust API communication.

# Features
Next.js & React: Server-side rendering (SSR), static site generation (SSG), and smooth client-side routing.

Node.js Backend: Fast and scalable server-side architecture.

Axios: Efficient, promise-based HTTP client for seamless API requests and handling.

Clean Architecture: Separation of concerns between the frontend UI and backend services.

# Tech Stack
Frontend: React, Next.js, HTML5, CSS3/Tailwind CSS

Backend: Node.js.

API Client: Axios

# Getting Started
Prerequisites
